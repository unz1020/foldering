# Presets

Presets are optional starting points for the Folder Schema Builder. They are data, not executable rules.

A preset must never create, rename, move, archive, or delete folders by itself. The user reviews and edits the schema first.

## Included

- `blank.json` — minimal generic schema
- `advertising-agency.json` — generic advertising-agency workflow

Community presets can be added without changing `@5level/core`.
