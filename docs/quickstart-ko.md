# 5-Level V0.2.1 빠른 시작

5-Level은 Windows와 macOS를 모두 대상으로 하는 개발 테스트 버전입니다.

- Windows: [`windows-quickstart-ko.md`](windows-quickstart-ko.md)
- macOS: [`mac-quickstart-ko.md`](mac-quickstart-ko.md)
- 지원 범위와 주의사항: [`platform-support.md`](platform-support.md)

공통 실행 명령:

```bash
npm install
npm run validate
npm run tauri:dev
```

처음에는 실제 업무폴더가 아니라 복사본 Workspace와 소수의 테스트 파일로 Review Mode 및 Undo를 확인하세요.
